# Proyek 75: 3D Card Tilt Effect (Generator Efek Kartu 3D Hover)

Proyek ini adalah generator interaktif untuk mempelajari pemrosesan efek transformasi 3D pada elemen web menggunakan **HTML5, CSS3, dan Vanilla JavaScript**. Proyek ini melatih pemahaman siswa mengenai perhitungan koordinat kursor mouse relatif terhadap elemen HTML dan penerapan properti CSS 3D (`perspective`, `rotateX`, `rotateY`, dan `translateZ`).
